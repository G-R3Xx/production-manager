# Production Manager V26.08.10.02

## No-print roll stock + explicit backing media

- Quick Quote roll-stock jobs now offer **No print** alongside CMYK, White and CMYK + White.
- Choosing No print keeps the selected roll-stock material cost, removes ink charges, clears print setup, sides, print direction, backing and laminate, and continues to finishing.
- **Used for backing** is now a checkbox on Roll Media materials, alongside Reverse printable.
- Only roll stocks marked **Used for backing** are offered as new backing choices in Quick Quote and the guided product builder.
- Existing saved product/quote backing selections remain visible so old work is not broken while materials are being updated.
- Backing materials with the same customer-facing name still group automatically and choose the best width by finished size, quantity and cost.
- The new backing capability is persisted in quote snapshots so edited Quick Quote lines keep the correct material capability.

# Production Manager V26.10.19.02

## Catalogue quote wizard uses images for laminate / backing

- In the visual catalogue quote builder, the **Laminate / backing** step now uses image cards instead of plain dropdown lists wherever images are available.
- Backing options now appear as visual tiles, including a **No backing** card.
- Laminate options now appear as visual tiles, including a **No laminate** card.
- Small-format **Cello / coating** now also uses image cards where possible, instead of only a dropdown list.
- Existing material-specific quote images are used first; where a custom material image has not been uploaded yet, the wizard falls back to the existing category artwork.
- Laminate/coating labour fields still appear automatically after a laminate/coating is chosen.

Version: V26.10.19.02

# Production Manager V26.10.19.06

## Catalogue image containment fix

- Catalogue-mode material image cards now use a fixed-height image viewport instead of forcing the card itself to a 4:3 aspect ratio.
- Uploaded material images are always displayed with full-image containment and a small safe inset, so the top, bottom and sides of the source image remain visible.
- The fix applies to substrate/material, roll media, laminate/backing and coating image cards.
- No material names, stock sizes, suppliers or SKUs have been reintroduced to image-only catalogue cards.

Version: V26.10.19.06

# Production Manager V26.08.25.06

## V26.08.25.06

- Quote creation keeps the enquiry summary, client/contact, site/reference and original enquiry request visible at all times.
- Photos, emails and other enquiry attachments now sit in their own collapsed "Photos, emails & attachments" section and can be expanded only when needed.
- Fixed enquiry correspondence overflowing/cropping on the right-hand side of the quote page. Attachment cards, email metadata/body previews and long addresses now wrap within the available quote width.
- Existing enquiry correspondence remains available through the same inline previews and Open original links.

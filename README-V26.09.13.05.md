# Production Manager V26.09.13.05

## Material workbook supplier placeholders

- New material rows may contain a Supplier name that does not yet exist in Production Manager.
- Preview clearly identifies that a placeholder supplier will be created.
- Apply creates one active placeholder supplier per new supplier name and links all relevant new materials to it.
- Placeholder suppliers are local PM suppliers only; they are not automatically pushed to MYOB. Complete contact, purchasing and MYOB details from Suppliers before first purchasing use.
- Duplicate existing supplier names remain a safe validation error.
- Blank template ADD rows are ignored until actual material details are entered.

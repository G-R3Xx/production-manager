# Production Manager V26.08.03.03

## Focused production job workflow

- The Production page is now a compact list of active jobs instead of displaying every job's full production detail.
- Each row shows the client and job, current unfinished production step, overall status, step progress and due date.
- Completed and deleted jobs are available in separate views so the active list stays clear.
- Clicking a job opens its own dedicated `/production/[job-id]` page.
- The dedicated job page contains the full artwork, item breakdown, production procedure, step checkoff, job controls and MYOB handoff.
- Job actions return to the dedicated job page after saving.
- Production Board and New Job alerts now link directly to the dedicated job page.
- Fast in-place production-step checkoff from V26.08.03.02 remains unchanged.

No database migration or WordPress plugin update is required. Continue using Tender Edge V2 Platform V3.3.13.

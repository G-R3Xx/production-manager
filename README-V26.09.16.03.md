# Production Manager V26.09.16.03

## Testing production setup

- Products now includes **Add testing production setup** beside the starter-product installer.
- The installer creates nine clearly labelled test machines, four test labour rules, twelve test processes and eight shared test Production Methods.
- Each of the eight starter products is assigned to its matching test Production Method automatically.
- If starter products are missing, the testing installer creates them before assigning production methods.
- All testing resources use the **TEST —** prefix and the installer does not overwrite real machines, processes or methods.
- Running the installer again does not duplicate records. Archived test resources are reactivated when needed.

## Test costing coverage

- Small format: Konica-style colour/mono click rates, setup/attendance labour, celloglaze, saddle stitching and calculated guillotine stacks.
- Wide format: flatbed direct print, roll print, roll-to-roll laminate, CNC/contour cutting, vinyl plotting, mounting/application and packing.
- Small-format starter products receive a default editable testing profile using machine clicks and the manager-calculator overhead/profit fields.
- Dummy prices and speeds are intended only for testing and can be edited under Production Setup.

## Version

App and WordPress catalogue version updated to **V26.09.16.03**.

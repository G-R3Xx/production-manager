# Production Manager V26.09.02.06

## Email recipient confirmation

- Quote email now opens a confirmation popup before sending.
- Artwork Approval email now opens the same confirmation popup.
- The saved client/contact email is prefilled but can be changed for that send.
- Recipient overrides are per-email only and do not overwrite the saved client/contact address.
- Quote email delivery status records the actual recipient used.
- Both workflows continue to send the online link plus the downloadable PDF attachment.

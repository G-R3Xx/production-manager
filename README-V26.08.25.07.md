# Production Manager V26.08.25.07

## V26.08.25.07

- Restored **Fixings and consumables** to normal product quote creation whenever Pickup / Delivery / Install is set to **Install**.
- Install fixings now work for signage, print-department and small-format quote lines, not only the separate Install-only service line.
- Staff can select Silicone, VHB / double-sided tape, Screws / anchors, special fixings and Other consumables.
- Each selected fixing shows an explicit **Allowed qty**, unit and **Cost / unit**, plus its calculated allowance cost.
- Fixing quantities are totals for the complete install line and feed the existing Sign Install costing, markup/profit/price-level calculation and staff-side fixing allowance summary.

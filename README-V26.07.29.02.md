# Production Manager V26.07.29.02

## Quick-quote style product builder

- Rebuilt normal product creation as a fast five-step client-side builder: Substrate, Size & quantity, Print, Finishing, and Fulfilment.
- Moving between builder steps and selecting materials/options no longer reloads the page or calls the server.
- All product choices are held locally and saved once on the final step.
- Substrate selection now uses searchable material cards and excludes laminate/eyelet consumables from the main stock list.
- Added actual laminate material selection inside the normal builder.
- Added Quick Quote-style eyelet setup, including placement presets, custom quantity prompt, optional hardware stock and per-eyelet labour.
- Normal finishing choices are saved as quote defaults and shared with WordPress in the same order.
- Existing advanced product rules and production sequences remain available under Advanced setup.
- Updated visible application and WordPress catalogue version to `V26.07.29.02`.

No database migration is required.

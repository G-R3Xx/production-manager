# Production Manager V26.07.28.10

## Product Build workflow simplification

- Moved normal production setup into the Product **Build** tab.
- Added guided material selection, including no physical material / customer supplied.
- Added visual production-action cards for print, laminate, cutting, application, eyelets, finishing, packing and installation.
- Added ordered workflow cards with earlier/later controls.
- Added optional per-step machine and labour selection only where relevant.
- Added live saved-workflow cost preview with Australian-dollar formatting.
- Production Manager now creates and maintains the Product manufacturing method in the background.
- Existing manual methods and legacy product configuration remain supported.
- Removed Manufacturing Methods from the day-to-day sidebar.
- Moved Manufacturing Methods, Production Steps, Machines and Labour under **Settings → Advanced production setup**.
- Updated visible application and WordPress catalogue version to `V26.07.28.10`.

No database migration is required.

# Production Manager V26.08.14.07

## Customer-facing job name / quote title

- New draft quotes now require an explicit **Job name / quote title**.
- The job name is shown at the top of the client-facing quote instead of deriving the heading from the first stock/product line.
- Existing quotes remain compatible; if no saved job name exists they retain the previous derived-title fallback.
- Existing quotes can be given or changed to a job name from the selected quote screen without rebuilding or repricing the quote.
- The saved job name carries into newly-created Artwork Approval project names, which in turn keeps the same project identity through Production.
- Quote cards and the selected-quote heading now surface the job name while retaining the client name.

## Preserved

- V26.08.14.06 customer-facing roll-media names on public quotes.
- Automatic MYOB Client / Supplier / Material background sync.
- MYOB OAuth refresh, pagination, Price Levels A-F and accepted-quote order workflow.
- Purchasing, MYOB Item Purchase Orders, Gmail SMTP PO email, PDF and send/sync history.
- Existing quote prices, line responses, artwork revisions and public quote workflow are unchanged.

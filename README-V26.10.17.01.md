# Production Manager V26.10.17.01

## Quote workspace redesign

- Reworked the selected quote workspace around the primary quoting task.
- **Create quote line** is now the first prominent action under the selected quote.
- Saved quote lines follow immediately underneath for fast review/editing.
- Job/status/client/MYOB controls are moved into a compact **Quote details & client actions** panel that is collapsed by default.
- Removed the exposed client-facing URL field; **Open client quote** remains available.
- Send quote, manual approval, mark sent, delete, lifecycle, enquiry correspondence, email history and MYOB controls are treated as secondary actions.
- Artwork approval is collapsed into a compact secondary section.
- Reduced visual density and repeated explanatory copy.
- Visual catalogue wizard from V26.10.16.04 remains unchanged.

Root folder: `production-manager/`

# Production Manager V26.09.16.02

## Editable starter product library

- Products now includes a one-click starter library for Cards, Carbon Copy Books, Booklets, DL Flyers, Corflute Signs, ACM Signs, Printed Roll Stock and Cut Vinyl Graphics.
- Starters are created as ordinary draft products, so every quote question, material, production method, name and SKU can be changed.
- The installer is safe to run repeatedly. Existing products with the same starter SKU or name are skipped, including removed products that can still be restored.
- Cut Vinyl Graphics has its own starter behaviour for vinyl grade and colour, cutting/weeding complexity, application tape, supply/application method, finished size and quantity.

## Product duplication

- Products can now be duplicated from either the Product Library card or the product detail page.
- A duplicate receives a fresh quote template and field/component identifiers, starts as a draft with no SKU, and keeps the source product's production method link.
- The copy opens immediately on Product details so it can be renamed and assigned its own SKU.

## Version

App and WordPress catalogue version updated to **V26.09.16.02**.

# Production Manager V26.08.27.09

## V26.08.27.09

- Artwork Approval PMS entry is now one colour per field instead of a single comma-separated text box.
- Staff can add or remove PMS colour rows and see a live screen swatch beside each entry while typing.
- PMS parsing now recognises a Pantone code even when staff add a friendly description, for example `PMS 557 C - Sage`.
- Added screen approximations for PMS 556/557/558 and White; unknown PMS references still use the neutral marker rather than inventing a colour.
- Existing saved PMS values remain compatible.
- The Artwork Approval imaging/print icon now uses a large-format roll printer/plotter style closer to signage production equipment.

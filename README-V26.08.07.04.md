# Production Manager V26.08.07.04

## Clear-substrate-only vinyl backing

- Vinyl backing is now only offered when the selected base substrate is identified as Clear or Transparent.
- Opaque substrates such as ACM, aluminium, PVC and corflute no longer show or save the vinyl-backing question.
- Products with mixed base-material choices can still configure backing once; the question appears only when the customer selects a clear/transparent base option.
- Backing material pricing also requires the clear base-material condition, preventing a hidden/stale backing choice from being charged against an opaque substrate.
- Existing grouped backing-media width selection remains unchanged for clear products.

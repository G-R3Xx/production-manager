# Production Manager V26.10.19.07

## Machine edit window viewport fix

- Machine **Edit** now opens in a viewport-centred overlay instead of an absolutely positioned popover anchored to the machine card.
- The editor is constrained to the browser window with responsive width and a maximum viewport height.
- Long machine forms scroll internally rather than extending off-screen.
- The **Save changes** action stays visible at the bottom of the scrolling editor.
- Clicking the shaded backdrop closes the editor.

Version: V26.10.19.07

# Production board slim signage details batch

- Simplified the fullscreen production board card body so it shows only production-relevant signage information.
- Board cards now summarise material/size/quantity, print method, laminate, next step, due date, assignee, progress, job link, updated time, and mark-done action.
- Removed verbose survey/artwork/internal notes from the large-screen card view.
- Step check/uncheck updates now touch the production item/job timestamp so reopened earlier steps are reflected on the board immediately after refresh.
- The board still determines the column from the first unchecked production step, so reopening an earlier step moves the job backward to the matching column.
- Version updated to V26.06.29.05.

# Plan and poster printing departments

Version: V26.07.15.09

## What changed

- Added Plan printing and Poster printing as first-class quick quote types.
- Added dedicated material/stock, size, sides, print colour, coating/laminate and finishing fields for those print departments.
- Added Plan Printing and Poster Printing columns to the fullscreen Production Board.
- Updated artwork approval prefill so plan/poster quote lines become their own production types instead of being forced into signage or small format.
- Updated production routing so plan/poster work lands in the correct department column for print tasks, while still moving to finishing and handoff columns when the next step requires it.
- Added Plan printing and Poster printing as product departments on the Products page.

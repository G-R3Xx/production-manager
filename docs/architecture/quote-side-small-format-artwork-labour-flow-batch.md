# Quote-side small format, artwork and labour flow batch

This batch keeps the new quote-side card builder direction and extends it so it works as the main quoting experience for both signage and small format.

## Direction

Products/templates stay in the background. A quote line starts with the type of work being quoted:

- Large format / signage
- Small format / print

Each path has its own card flow, wording and colour treatment so small format does not feel like signage with fields removed.

## Added to every quote line

Every quote line now includes an artwork step:

- No — client supplied
- Yes — artwork required, with hours entered

Artwork hours are costed using the shared labour rate of `$66/hr`, then the global markup/profit multipliers are applied with the rest of the line.

## Signage flow

The signage flow now follows:

1. Choose base material family
2. Choose thickness
3. Choose colour/finish
4. Enter sign size
5. Artwork required or client supplied
6. Choose print method
7. Choose roll media/cut vinyl if required
8. Choose ink if required
9. Choose sides / clear acrylic print direction
10. Choose laminate
11. Choose finishing
12. Review/save

If laminate is selected, the flow asks for laminate application hours.

If finishing is selected, the flow asks for the labour time for each selected process. Eyelets also retain placement/quantity presets and now use entered hours per eyelet.

## Small format flow

Small format gets its own purple card flow:

1. Choose print item type
2. Choose paper/card stock
3. Choose size
4. Artwork required or client supplied
5. Choose sides
6. Choose print colour
7. Choose cello/coating
8. Choose small-format finishing
9. Choose quantity
10. Review/save

Small-format finishing includes extra cutting/trimming, folding, scoring, stapling, numbering and padding/tape, each with labour hours entered when selected.

## Pricing

The live price panel now combines:

- base material or paper/card stock cost
- artwork labour if required
- print/ink charges
- roll media where required
- laminate/coating material
- laminate labour where required
- selected finishing labour
- eyelet material and labour where required
- global markup multiplier
- global profit multiplier

The aim is to keep quoting visual and guided while keeping Products/templates out of the way.

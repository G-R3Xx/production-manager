# Roll stock panelised wide print / laminate batch

When a signage print is wider than the selected roll stock or laminate width, the quote calculator now automatically panels the print instead of under-counting a single roll length.

Example:

- Finished size: 2000 × 4000mm
- Roll width: 1370mm
- Panel result: 2 panels at 1000 × 4000mm
- Roll media used: 8lm
- Laminate used: 8lm, rounded to whole metre charging as required

The calculator keeps the entered width as the panelled direction when both dimensions exceed the roll width. Normal smaller work still nests across the roll and rounds laminate to the next full metre across the total quote quantity.

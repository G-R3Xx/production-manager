# Quote ink whole-square-metre rounding and optional labour

## Ink usage

Large-format/signage ink is now billed using the whole quote-line quantity rather than rounding every item separately.

- The finished artwork area is calculated across quantity and printed sides.
- For roll-media jobs, the area follows the same whole-linear-metre media rounding used by the selected roll stock.
- The resulting ink area is rounded up to the next whole square metre.
- The cost breakdown and Current item panel show calculated artwork area, media-adjusted area where applicable, and billable ink area.

Example: a 9100 × 940 mm single-sided Walltex item uses 8.554 m² of artwork. When 9.10 lm of media is billed as 10 lm, the media-adjusted ink area is 9.40 m² and the billable ink amount is 10 m².

## Optional labour inputs

Production labour inputs no longer block saving when blank or zero:

- print setup labour
- laminate application labour
- artwork labour
- finishing labour fields (already optional)

Blank and `0` are treated as no labour charge. Install duration remains required when Install is selected because it defines the separate install service line.

# Quotes saved line snapshot clarity fix

This batch clarifies that quote lines are saved snapshots. Changing the quote card selections above the saved quote lines does not edit an already-saved line.

Changes:

- Renamed the builder submit button to **Save current line to quote**.
- Renamed the summary block to **Current unsaved line**.
- Renamed the quote lines list to **Saved quote lines**.
- Added helper text explaining that saved lines do not update when the form above changes.
- Added a Remove button for saved quote lines so incorrect/test lines can be deleted before saving the corrected current line.

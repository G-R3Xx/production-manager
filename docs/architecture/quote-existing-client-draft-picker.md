# Quote existing-client draft picker

Version: `V26.07.23.10`

The New draft quote form now supports two explicit entry modes:

- **Choose existing client** searches the active client library, fills the company/contact/phone/email/default discount fields, and links the quote to that client.
- **Enter manually** keeps the quote unlinked and supports new or one-off client details.

Copied client details remain editable on the quote. Editing these fields does not update the saved client record. Quotes started from an enquiry or survey retain their source details and linked client selection when available.

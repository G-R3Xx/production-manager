# Workflow pages main-content-width layout batch

This batch changes the workflow-heavy pages so the main working area gets full page width instead of losing horizontal space to permanent left-side panels.

Updated pages:

- Artwork approvals
- Quotes
- Surveys

Changes:

- Create/switch panels moved out of permanent sidebars and into compact top workflow controls.
- List/selection areas are now horizontal, scrollable chips/cards near the top.
- Main detail/setup/build sections now render full width.
- Large proof/quote/survey details have more horizontal room.
- Creation forms are placed in expandable details blocks so they are available when needed without dominating the page.
- Status/meta cards were tightened into compact pills where they were wasting space.

The goal is to keep the page focused on the active job: proof setup and preview, quote line building, and survey workflow details.

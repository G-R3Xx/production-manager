# Products less-clutter no-training flow batch

This batch simplifies the spreadsheet-style product creator so the normal setup path is less overwhelming.

## What changed

- Reworked the Products page to focus on one main flow:
  1. Product
  2. Questions staff answer
  3. Costing attached to each answer
- Moved optional spreadsheet rows into a collapsed advanced section.
- Removed the right-side preview rail from the main editor.
- Reduced the product hero and status cards.
- Changed answer-line editing from large stacked cards into a compact quote-sheet style row layout.
- Reduced blank answer rows so custom questions do not open with a huge form.
- Kept quick-add buttons for Size, Print Type, White Ink, Laminate, Finishing and Quantity.
- Added a small Quick Check panel instead of the heavier live recipe side panel.

## Design intent

Normal product creators should not need to understand configurators, hidden rules, or separate component rows.
They should add the quote question, then set what each answer adds:

- No extra cost
- Material from size
- Parts per sheet
- Sheets per item
- Metres per item
- $ per m²
- $ each

Advanced recipe rows still exist for always-included labour, outsourced supplier rows or unusual jobs, but they are no longer the first thing users see.

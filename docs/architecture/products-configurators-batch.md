# Products + Configurators Batch

This batch extends the working tenant-aware admin shell into the commercial catalog layer.

## Included

- Products page with create form and listing
- Configurator templates page with starter template creation
- Quote page scaffold showing the next handoff point
- Dashboard summary cards for products and configurator templates
- Server-side helpers for product and configurator reads/writes

## Current intent

This batch is deliberately focused on catalog setup, not full quote line calculation yet.
The next logical batch should introduce quote headers, quote lines, and configurator snapshot preservation.

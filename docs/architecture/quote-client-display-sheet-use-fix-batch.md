# Quote client display + sheet use fix

- Public client quote display now only treats a line as `Sign Install` when the quote line title itself is an install/service line.
- Signage lines with `Dispatch: Install` in their option summary remain signage lines on the public quote.
- Quick quote sheet usage now calculates panelled sheet count when the finished size is larger than a parent sheet.
- Large finished sizes now show a practical parent-sheet requirement instead of the confusing "does not fit one parent sheet" message.
- Version updated to `V26.07.15.04`.

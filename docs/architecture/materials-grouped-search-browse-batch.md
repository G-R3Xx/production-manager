# Materials grouped search/browse batch

## Goal

Reduce clutter on the Materials page now that the material setup form is more useful. The page should not dump every material record onto the screen all the time.

## Changes

- Reworked the existing material library panel into **Find materials**.
- Materials are hidden by default until the user searches or opens a group.
- Added material browse groups:
  - **Signage** — sheet media, roll media and roll laminate.
  - **Small format** — paper stock, card stock, cello/coating and binding.
  - **Shared / consumables** — fixings, finishing consumables, hardware and other each/box items.
- Added a compact search form with:
  - search text
  - group filter
  - search button
- Search covers material name, SKU, supplier name, material type, UOM, GSM/thickness and notes.
- Material edit/delete/restore controls remain available on each result card.

## Why

The Materials page should behave more like Products: create the thing on the left, then search/browse only when you need to edit or inspect an existing record. This keeps the page from feeling like a huge database list.

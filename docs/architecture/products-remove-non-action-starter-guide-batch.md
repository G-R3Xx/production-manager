# Products remove non-action starter guide batch

## Goal
Keep the Products page aligned with the PCPartPicker-style build flow by removing non-action starter guide cards that looked clickable but did not perform an action.

## Changed
- Removed the lower "Starter guide" card grid shown when no product was open.
- The page now focuses on the actual actions only:
  - create a product
  - select a starter template in the create form
  - open/search existing products
- This reduces clutter and avoids cards that look interactive but are only explanatory.

## Result
The Products landing state is cleaner and closer to the PCPartPicker flow: choose/create the build first, then select parts inside the builder.

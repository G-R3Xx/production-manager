# Manufacturing methods guided builder

Version: V26.07.28.08

The manufacturing-method page now explains where methods sit in the Product and WordPress workflow and replaces the flat technical form with a four-step guided builder:

1. Choose a department and recognisable method name.
2. Select the main material, including a clear no-material path for install-only/service work.
3. Add production steps in the actual order used, with move-up, move-down and remove controls.
4. Review the method, with waste, markup and profit kept under Advanced pricing defaults.

The page also shows setup-readiness counts for materials, production steps, machines and labour, provides direct links to missing resources, labels the price-test fields, formats money in Australian dollars, and keeps archived methods out of the active list.

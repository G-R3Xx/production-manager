# Quote saved product picker + sheet use batch

- Quick quote current-item panel now shows signage sheet usage from the base sheet material and finished size, multiplied by quote quantity.
- The second quote tab is now labelled `Use saved product` and opens products configured on the Products page instead of the old advanced step builder.
- Saved product tab lets staff pick a pre-built product, answer its saved quote options, add quantity, and add the line to the quote.
- The older advanced builder remains internally available for custom component workflows, but it is no longer the main second tab.

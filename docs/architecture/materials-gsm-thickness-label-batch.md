# Materials GSM / Thickness label update

Updated the Materials create/list UI so the existing `gsm` field is presented as **GSM / Thickness**.

This keeps the current database field unchanged while making the form clearer for both paper/card materials and rigid substrates such as acrylic, ACM, PVC and corflute.

Changes:
- Create Material label: `GSM` → `GSM / Thickness`
- Placeholder: `eg 250gsm or 3mm`
- Material list display: `GSM/Thickness`

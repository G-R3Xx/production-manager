# Production Manager V26.07.30.07

## Denser Product Library

- Product cards now use a compact responsive grid.
- Wide screens show up to five cards across; normal desktop widths show four where space allows.
- Reduced card padding, title size, metadata spacing and status-chip size.
- Product names still wrap safely without forcing oversized cards.
- Existing product creation, filtering and Guided Builder behaviour are unchanged.

## WordPress gallery companion update

Use WordPress plugin V3.3.1 with this build. Gallery sync now reports failed image imports instead of silently publishing a partial gallery, and includes a MIME-based import fallback for Supabase/CDN image URLs.

Visible application/catalogue version: `V26.07.30.07`.
No database migration is required.

# Production Manager V26.07.28.11

## Labour & time rates usability rebuild

- Renamed the page from **Labour operations** to **Labour & time rates**.
- Rebuilt the page as a guided three-step setup instead of a single technical row of fields.
- All labour time is now entered and displayed in plain minutes.
- Production Manager converts scalable minute values to the existing hours-per-unit costing format automatically.
- Existing labour records are converted back to minutes for display and editing; no records need to be recreated.
- Added clear calculation choices for fixed time, square metres, sheets, linear metres and finished items.
- Added plain-English descriptions explaining when each calculation type should be used.
- Added common quick-start templates for print setup, mounting/application, trim/cut and packing.
- Added a live Australian-dollar cost example while editing.
- Added a clear minimum-charge explanation and live indication when the minimum applies.
- Replaced the floating edit panel with an inline expandable editor inside each labour card.
- Added clearer active and archived sections, work-area labels and cost summaries.
- Added validation for missing names and zero hourly rates.
- Updated the visible application and WordPress catalogue version to `V26.07.28.11`.

No database migration is required.

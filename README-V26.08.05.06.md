# Production Manager V26.08.05.06

- Adds **Base material selected by customer option** to the guided product builder.
- Lets one product link multiple real inventory materials, such as clear acrylic in 3 mm, 4.5 mm and 6 mm.
- Adds an editable customer question label and friendly display label for every material choice.
- Keeps one selected material as the normal default and Production Recipe baseline.
- Applies only the selected material row to internal quote costing and website pricing.
- Sends the new material choice through the existing WordPress catalogue and option-image rules.
- Retains the approved production-job priority layout, WooCommerce order recovery and option-image functionality.

Use with Tender Edge WordPress plugin V3.3.32. No database migration is required.

# Production Manager V26.08.04.06

## WordPress client-link repair

- Uses the permanent Production Manager client ID from a linked WordPress customer before attempting email or company-name matching.
- Re-sent WooCommerce orders repair the linked client on both the imported quote and its existing production job.
- Production lists can retrieve the client logo from either the linked quote or the production job.
- Matching order is permanent client ID, email, company name, then the configured Cash Sale client.

Use with Tender Edge WordPress plugin V3.3.25.

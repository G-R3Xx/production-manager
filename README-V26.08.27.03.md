# Production Manager V26.08.27.03

## V26.08.27.03

### Calendar drag-and-drop assignment fix

- Week-view calendar cells now act as both a date and staff assignment target.
- Dragging an unscheduled task/process/procedure onto a staff member on a particular day now saves both that date and that staff member.
- Dragging scheduled work between staff rows now reassigns it even when it stays on the same date.
- Dropping onto the Unassigned row explicitly clears staff assignment while retaining the chosen date.
- Month-view drag-and-drop still changes the date only and preserves the current assigned team.

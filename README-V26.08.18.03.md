# Production Manager V26.08.18.03

## Factory-floor job sheet redesign

- Reworked each printed production line into a staff process sheet rather than a pricing/calculation report.
- Added a clear **Stock Required** section using friendly material names and total physical/linear stock required for the full quote line.
- Stock requirements distinguish substrate/stock, print media, laminate and backing where applicable.
- Approved artwork remains full-width as the visual production reference.
- Added a structured **Processes** sign-off table with Done, By, When and Sign columns on every process.
- Standard print workflow includes Artwork received, Print-ready files and RIP setup, followed by the production steps generated for that item.
- Existing digitally completed PM steps print as already checked with their user/time; uncompleted steps remain blank for factory sign-off.
- Added a final LINE COMPLETE sign-off row plus production notes/issues and final QC/date area.
- Removed detailed pricing allowances/labour calculations from the printed factory sheet; those calculations remain available inside Production Manager.
- Existing Production, MYOB, Purchasing, quote, artwork approval and website workflows are unchanged.

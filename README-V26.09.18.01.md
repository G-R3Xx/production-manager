# Production Manager V26.09.18.01

## Automatic process labour in Quick / Custom quotes

- Quick / Custom quote lines now use the labour operation linked to each selected process.
- Automatic labour supports fixed time, per item, per sheet, per square metre, per linear metre and calculated guillotine stacks.
- The configured hourly rate, calculation value and minimum time are applied automatically.
- Existing minute fields are now optional actual-time overrides. Leaving them blank uses the automatic process calculation.
- The quote editor identifies automatic labour in green and manual overrides in orange.
- Automatic labour is applied to print, laminate/cello, signage finishing and small-format finishing operations.
- Guillotine labour uses parent sheets, cuts per stack, maximum stack sheets, cuts per minute and setup time.
- If a selected operation has no linked automatic labour rule, PM says so and retains manual time entry.
- Existing saved Quick / Custom line snapshots remain compatible.

App and WordPress catalogue version updated to **V26.09.18.01**.

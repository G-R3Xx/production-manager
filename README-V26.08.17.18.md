# Production Manager V26.08.17.18

- Added roll-stock Drop direction: Auto / best yield, Vertical drops, or Horizontal strips.
- Added configurable overlap between adjacent drops/strips.
- Oversized Auto roll jobs default to vertical drops when both finished dimensions exceed the selected roll width.
- Roll media, backing, laminate and ink usage now follow the selected drop direction and overlap.
- Quote snapshots retain drop direction, overlap, drop count and calculated panel dimensions for production history.
- Production instructions show the selected drop layout prominently.
- Printable job sheets show an INSTALL LAYOUT instruction including drop count, approximate drop size and overlap.
- Existing quote/artwork/production/MYOB/Purchasing/website workflows retained.

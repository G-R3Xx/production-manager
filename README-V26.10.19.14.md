# Production Manager V26.10.19.14

Material Price Manager billing controls are now editable directly in the live grid.

- Added a **Billing increment** column to Material Price Manager.
- Sheet/card/paper rows can choose Auto recommended, Exact usage, 1/4 sheet, 1/2 sheet or Full sheet.
- Roll media/laminate/cello rows can choose Auto 0.5m, Exact usage, 0.25m, 0.5m or 1m.
- Values save to the existing material billing fields used by quote costing.
- New material rows can set billing immediately from the grid.

Version: V26.10.19.14

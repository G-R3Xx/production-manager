# Production Manager V26.08.17.06

## Approved artwork visible on printable job sheets
- Job sheets now display the approved artwork itself in the **APPROVED ARTWORK** panel so production staff can identify the job visually at a glance.
- Approved image proofs continue to display directly.
- Approved PDF proofs now render their first page as a clean image preview in the browser and that rendered canvas is included when the job sheet is printed/saved to PDF.
- The approved artwork title, filename and revision remain below the preview for traceability.
- The original approved artwork link remains available on screen as a secondary staff-only action and is hidden from the printed job sheet.
- If PDF preview rendering is unavailable, the job sheet falls back to the existing approved-PDF reference rather than losing the artwork record.

## Preserved
- Safe 15-second server-data refresh and MYOB redirect fix from V26.08.17.05.
- Client artwork watermarking, artwork approval workflow, MYOB Item Orders, Purchasing, Gmail email workflows, quote lifecycle and production features remain intact.

# Production Manager V26.10.17.08

## Changes
- Open quote search now filters automatically while typing with a short debounce.
- Removed the separate Search button and added a one-click clear control.
- Existing quote results stay inside a fixed-height vertically scrollable panel.
- Default Open quote view still shows only the 3 most recent active quotes.
- CURRENT clock now synchronises to server time before formatting in Australia/Sydney, so it no longer depends on the PC/browser clock being correct.
- Weather remains independent from clock timezone handling.

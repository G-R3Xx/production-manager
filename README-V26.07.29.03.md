# Production Manager V26.07.29.03

## Default instant Guided Product Builder

- Made the Guided Product Builder the default Create/Edit Product experience.
- Product creation now opens directly into the guided substrate-first workflow.
- Material, Size, Print, Media & Ink, Laminate, Finishing, Supply and Review are client-side tabs.
- Moving between option tabs no longer navigates to a new page, reloads product data or waits for the server.
- Choices remain in memory while staff move between tabs and are saved once from Review.
- Staff choose both the options allowed on a quote and the default answer shown first.
- Eyelet placement uses the same proven Quick Quote presets and optional stock link.
- Existing products and legacy roll-print values are normalised into the new builder.
- Advanced product rules and uncommon production sequences remain available through Advanced setup.
- Website publishing remains optional and uses the same saved quote fields.
- Updated visible application and WordPress catalogue version to `V26.07.29.03`.

No database migration is required.

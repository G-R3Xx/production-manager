# Production Manager V26.08.27.08

## V26.08.27.08

- Artwork Approval PMS colour matching now displays compact colour swatches beside each PMS code in the Sign Specification panel.
- Multiple PMS requirements each receive their own swatch and code, for example PMS 186 C and PMS 3005 C.
- The PMS number remains the authoritative approval/production reference; the on-screen swatch is explicitly labelled as an RGB visual guide only.
- Common signage Pantone colours, process colours, greys and metallic visual cues are recognised locally with no external colour service or network lookup.
- Unknown or special PMS references are never given a fabricated colour; they retain the PMS code with a neutral swatch marker.
- The same swatches appear on both the staff Artwork Approval preview and the client approval page.

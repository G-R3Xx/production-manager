# Production Manager V26.10.19.12

## Shop operation cost preview clarity

- Shop Operation live preview now separates **Labour** and **Consumable / material** costs.
- The large total is now the **raw operation cost before markup and profit**, rather than a labour-only number.
- Minimum labour time is reflected in the one-unit example.
- Linked consumables use the saved material purchase cost, pack/stock quantity and wastage rules so the preview matches quote costing.
- When labour and consumable bases cannot be combined without quote dimensions (for example labour per book but tape per linear metre), the material/total correctly shows **Calculated on quote** instead of inventing a number.
- Multi-unit examples show labour + material + raw total where the bases align (for example 10 eyelets).
- Machine setup navigation now consistently calls the simplified area **Shop operations** instead of Labour & time.
- Saved-operation cards explicitly label labour-only base costs to avoid confusing them with full operation costs.

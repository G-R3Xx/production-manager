# Production Manager V26.10.16.04

## Visual catalogue quote wizard

- Reworked the Visual catalogue Quick / Custom quote entry into a genuine step-by-step wizard instead of embedding the existing long quote form in a modal.
- One decision is shown per screen with a progress indicator.
- Base product, substrate/material, artwork, print method, roll media, ink and simple sides choices use large clickable visual tiles.
- Simple selections advance automatically to the next screen. Screens that require dimensions, labour or other extra input use Back / Continue navigation.
- The wizard continues to use the existing Production Manager costing, material usage, labour, dispatch and quote-save logic underneath.
- Final screen uses Add quote line and remains blocked until all required fields are complete.
- Existing List quote-entry layout is unchanged.

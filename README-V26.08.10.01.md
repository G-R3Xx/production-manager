# Production Manager V26.08.10.01

## Quick Quote reverse-print backing

- Quick Quote now shows **Backing** whenever a reverse-print-capable roll media is set to **Reverse print**.
- Backing choices include **No backing** plus eligible roll media grouped by customer-facing name.
- When several backing roll widths share the same customer-facing name, Production Manager automatically selects the lowest-cost suitable width for the finished size and quantity.
- Backing material usage is costed in linear metres using each material's configured roll billing increment.
- Backing remains hidden and cannot add cost for Standard/Positive print.
- Laminate remains available independently of backing.
- Reverse-printable roll media now requires a print-direction choice in Quick Quote, matching clear acrylic behaviour.
- Backing selection and the actual chosen stock are saved in quote snapshots for later editing.

# Production Manager V26.08.25.09

## V26.08.25.09

- Simplified the **client-facing quote line specification** for signage products.
- Client quote headlines now show only the main sellable specification: **material/product + finished size + laminate**.
- Removed internal production information from the client view, including parent-sheet size, calculated sheet usage, print method, ink, print direction, backing/build method and other production/setup detail.
- Install lines no longer expose the selected fixing/consumable breakdown to the client; those allowances remain available to staff.
- Internal quote/staff data is unchanged; this is a client-view presentation change only.

## V26.08.25.08

- Added a dedicated **Access equipment markup multiplier** in Settings / Company pricing. Access-equipment hire now uses this markup instead of the global markup, while the normal profit multiplier, client MYOB price level factor and quote discount still apply.
- Restored **Fixings and consumables** to normal product quote creation whenever Pickup / Delivery / Install is set to **Install**.

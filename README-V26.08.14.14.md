# Production Manager V26.08.14.14

## Client quote cancelled-line visibility

- Client-cancelled quote lines are now completely hidden from the public/client quote.
- Cancelled lines remain stored internally in Production Manager for audit/history.
- Revised/resend quote totals are calculated only from visible active lines.
- Historical `clientRevisionExcluded` lines continue to stay out of the client-facing scope.
- No changes were made to MYOB, Purchasing, Gmail quote/PO sending, pricing, or the internal quote-line history.

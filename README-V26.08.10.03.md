# Production Manager V26.08.10.03

## Client quote clarity and printing

- Client quote line summaries now show Standard/Positive/Reverse print direction when saved on the quote line.
- Reverse-print lines show the selected backing as `Backed in ...` (for example `Backed in White`).
- White-only ink is recognised in the client summary.
- Added a Print button to the public client quote view.
- Printing hides the response controls and print button, removes the screen background/shadows, and avoids splitting quote lines where possible.

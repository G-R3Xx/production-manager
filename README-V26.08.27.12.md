# Production Manager V26.08.27.12

## V26.08.27.12

- Production Board now groups active production line items by **job within each workflow column** instead of repeating the full client/job card once for every quote line.
- A job with S1, S2 and S3 all currently in Printing now appears as one Printing card with three clearly separated line-item sections.
- Each line keeps its own production details, next step, progress and **Mark done** action, so line-level workflow control is not lost.
- If lines from the same job genuinely reach different stages, the job can still appear once in each relevant column (for example one Printing group and one Finishing group). This reflects real work in progress rather than duplicate cards.
- Production Board column counters now count grouped jobs in that column, and the header reports unique active jobs rather than raw line-item cards.
- The grouped job header now also shows the project/job name beside the quote number where available.

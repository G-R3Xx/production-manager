# Production Manager V26.08.21.03

## V26.08.21.03
- Calendar cards now lead with the job number and job name, so staff can identify the job before the process/procedure.
- The second line now shows the client and the specific process/procedure (for example `Locker Decals · Cut / route / finish · S1`).
- The same job-first hierarchy is used in week/month cards, unscheduled work, agenda rows and the scheduling drawer.
- Added a small `↗` shortcut on calendar cards to open the complete job without losing the existing click-to-schedule behaviour.
- Card hover text now includes job, client, procedure and process type for extra context.

No database migration is required.

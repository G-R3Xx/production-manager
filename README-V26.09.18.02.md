# Production Manager V26.09.18.02

## Saved-product custom dimensions

- Selecting **Custom** from a saved product's size option now reveals **Finished width (mm)** and **Finished height (mm)** inputs.
- The custom dimensions feed material, ink, laminate, machine and process-labour calculations.
- The dimensions are included in the option summary and saved quote-line configuration.
- Existing preset sizes and saved quote lines remain compatible.

App and WordPress catalogue version updated to **V26.09.18.02**.

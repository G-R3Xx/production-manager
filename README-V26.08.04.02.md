# Production Manager V26.08.04.02

## Website client accounts

- Client setup now includes COD, 7 Day Account, 14 Day Account and 30 Day Account terms.
- Staff can enable website access and securely invite one or more company contacts.
- Clients receive their username and an expiring password setup link; readable passwords are never emailed.
- The website user carries the permanent Production Manager client ID for reliable WooCommerce order matching.
- Account terms and calculated due dates remain internal and flow into the website order, production job and MYOB sync data.
- New or unlinked website customers continue to use the configured Cash Sale client.

Requires Tender Edge WordPress plugin V3.3.14.

# Production Manager V26.08.06.03

## Numeric holes and material-linked vinyl backing

- Replaces drilled-hole presets with one direct **Number of holes per sign** field.
- Shows an optional **Hole position / details** note whenever the hole count is above zero.
- Calculates Silver or Black standoff stock from the entered holes per sign, then multiplies it by the quote or order quantity.
- Adds website image-rule choices for **Any number above 0**, **0 / none**, and **Any entered text**, avoiding a separate image rule for every possible hole count.
- Lets each rigid-sign product offer selected real roll-media materials as vinyl backing choices.
- Calculates the selected backing film from finished dimensions, roll width, quantity and the product waste allowance path used by other roll stock.
- Pairs with Tender Edge Website Platform V3.3.34 for conditional fields, numeric image matching, live pricing, cart and order handoff.

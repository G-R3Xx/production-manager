# Production Manager V26.10.19.03

## Catalogue material selections are image-first

- Removed redundant material name, sheet/roll size, supplier and SKU text from Catalogue-style material cards.
- Substrate/material selection now shows clean image-only cards with the selected checkmark.
- A single material choice no longer stretches across the full modal; image cards keep a consistent catalogue size.
- Roll media, laminate/backing and small-format coating material cards use the same image-only presentation.
- Names remain available to accessibility tools and as hover titles, while internal stock-size selection stays automatic and is not exposed as a quoting decision.

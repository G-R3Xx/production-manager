# Production Manager V26.08.17.12

## Website product page: independent desktop scrolling

Adds an installable companion WordPress plugin under `wordpress/tender-edge-product-split-scroll/`.

Desktop WooCommerce product pages can now keep the product gallery and the Product Manager configurator in two independently scrollable columns:

- wheel over the left gallery → only the gallery scrolls;
- wheel over the right product/configurator → only the configurator scrolls;
- scroll chaining is contained inside each pane;
- existing fixed quantity / price / Add to Cart controls are not modified;
- tablet/mobile below 1024px keep normal single-page scrolling;
- layout is recalculated on resize and when option-driven gallery/configurator DOM is replaced.

An installable plugin ZIP is included at:

`wordpress/Tender-Edge-Product-Split-Scroll-V1.0.0.zip`

No Production Manager pricing, MYOB, Purchasing, email, artwork, quote or production workflow logic changed in this build.

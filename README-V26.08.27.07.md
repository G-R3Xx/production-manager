# Production Manager V26.08.27.07

## V26.08.27.07

- Artwork Approval PMS colour matching is now entered manually by staff per proof page instead of being inferred from the quote substrate/material colour.
- Added a Required PMS colours field to each proof page; multiple colours can be entered comma-, semicolon- or line-separated (for example PMS 186 C, PMS 3005 C).
- The client Sign Specification shows a PMS colour matching row only when staff have entered a requirement.
- PMS colour requirements are stored per artwork revision so the client approves the exact colours released with that revision.
- Changing PMS colours after an approval has been sent/approved moves the approval into a new revision and resets that proof page to pending client approval.
- Final client approval wording now explicitly includes required PMS colour matching.
- The previously added Pickup / delivery / install specification remains unchanged.

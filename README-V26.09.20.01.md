# Production Manager V26.09.20.01

## Faster quote-line saving

- Quote lines, artwork state and production state now load in the first parallel quote-page request after a save.
- The Quotes page no longer reloads the complete enquiry archive whenever a quote line is added or updated.
- Quote-card branding now uses a lightweight enquiry ID and logo lookup.
- The quote carousel loads compact quote summaries instead of every quote's full MYOB payload and lifecycle record.
- A legacy customer-pricing cleanup no longer scans the customer table during normal production requests.
- Quote calculations, saved products, client logos and linked enquiry correspondence remain unchanged.

App and WordPress catalogue version updated to **V26.09.20.01**.

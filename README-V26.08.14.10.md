# Production Manager V26.08.14.10

## Quote response workflow + branded quote email

- Quote-line alerts now deep-link directly to the correct quote and affected line.
- Existing quote-line alerts are repaired at display time from their stored payload, so older alerts also navigate correctly.
- The affected quote line opens and is visually highlighted when arriving from an alert.
- Client requested-change notes are surfaced prominently beside the selected quote heading, with links to the affected lines.
- Quote emails now use the workspace company logo and branded Tender Edge-style layout while retaining the existing Gmail sender and public quote response link.
- Existing inline quote-line editing, Gmail sending, MYOB sync, Purchasing and PO email workflows are unchanged.

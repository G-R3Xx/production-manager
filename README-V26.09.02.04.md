# Production Manager V26.09.02.04

## Quote PDF email support

- Quote emails now include a branded PDF copy of the quote as an attachment.
- The normal online quote link remains in the email.
- Locked-down clients can review the attached PDF and reply with APPROVED or requested changes.
- Staff can use **Mark accepted (email/manual)** to record an offline/email acceptance using the same quote acceptance workflow.
- The PDF uses customer-facing quote descriptions only; internal stock usage, calculated linear metres, SKUs and labour details stay hidden.
- PDF header uses the configured company/Tender Edge logo and company details.

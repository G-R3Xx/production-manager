# Production Manager V26.08.04.01

## Production job page priority layout

- The dedicated job page now puts the actual production work immediately below the job header.
- Priority production instructions and finished-item details appear first within each production item.
- Procedure checkoff appears before print-ready artwork controls.
- Job settings, due date, assignment and billable variations move below the production work.
- The administrative settings and variation form is collapsed by default and opens only when needed.
- MYOB order handoff remains at the bottom after the production workflow.

No database migration or WordPress plugin update is required. Continue using Tender Edge V2 Platform V3.3.13.

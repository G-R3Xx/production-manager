# Production Manager V26.08.17.08

## Job-sheet PDF filename

- The printable Production Job Sheet now temporarily sets the browser document title before opening the print dialog.
- Save as PDF therefore defaults to `QUOTE/JOB NUMBER - JOB NAME.pdf` instead of `Production Manager.pdf`.
- Characters that are invalid in Windows filenames are sanitised automatically.
- The normal Production Manager browser-tab title is restored after printing.
- No pricing, MYOB, Artwork Approval, Purchasing, Gmail or Production workflow behaviour was changed.

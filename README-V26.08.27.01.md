# Production Manager V26.08.27.01

## V26.08.27.01

- Added a standoff mounting add-on to rigid signage/panel quote lines. The control is only shown for panel/sheet materials, never roll stock.
- Standoff choices are populated automatically from standoff materials in the Materials library, including Silver/Black or other standoff products already configured.
- Staff enter the standoff quantity per finished item; Production Manager multiplies that by quote quantity automatically.
- Standoff cost uses the selected material's per-each cost (including pack/box quantity conversion where configured) and then follows the normal quote markup, profit and client price level calculation.
- The selected standoff type and quantity are preserved in the structured quote snapshot and are visible as a clean client-facing add-on on the public quote.

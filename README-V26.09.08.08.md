# Production Manager V26.09.08.08

## Job workspace invoicing action

- Added a prominent **Create invoice →** primary action when the current job stage is **Invoice required**.
- The action opens the existing Production Manager invoice builder for that job.
- The button is only shown to roles already authorised for invoicing (Owner, Manager and Accounts) and only when the job has an accepted/converted quote.
- Existing stage links and invoicing permissions are unchanged.

App version updated to **V26.09.08.08**.

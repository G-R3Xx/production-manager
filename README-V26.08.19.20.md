# Production Manager V26.08.19.20

- Breaks Production into the real item-level procedure records used by the Production workspace and board.
- Adds RIP / setup before Print for new production work and safely reconciles it into existing print jobs.
- Marks reconciled RIP / setup complete when the matching Print procedure was already completed, so old jobs do not move backwards.
- Shows RIP / setup, Print, Laminate, Apply / mount, Cut / route / finish, Pack and the other applicable procedures as separate Calendar work cards.
- Keeps each procedure inherited from the main Production or Dispatch team and date until a deliberate step override is saved.
- Supports assigning one or multiple staff and an individual due date to every procedure without a page reload.
- Adds a one-click Use process defaults action to remove a procedure override and resume inheritance.
- Hides the broad Production calendar card when real procedure cards exist, avoiding duplicate scheduling work.
- Keeps procedure completion tied to the Production Board check-off state; completed steps remain hidden unless Show completed is enabled.

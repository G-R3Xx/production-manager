# Production Manager V26.10.19.04

## Visual pickup / delivery / install choices

- Catalogue quote mode no longer uses a dropdown for Pickup / Delivery / Install.
- The dispatch step now shows large visual cards for Pickup, Delivery and Install.
- Standalone service quotes also use visual cards for Pickup, Delivery, Install and Access Equipment.
- Service details appear only after the visual option has been selected.
- Materials → Quote wizard category images now includes dedicated image uploads for Pickup, Delivery, Install and Access Equipment.
- A custom image uploaded for each service option is used immediately in the catalogue. Until then the existing service image is used as the fallback.
- The Continue button on the standalone Service Type step now remains disabled until a service card is selected.

Version: V26.10.19.04

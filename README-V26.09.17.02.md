# Production Manager V26.09.17.02

## Quote client link correction

- A selected quote no longer falls back to the source enquiry's client when its own saved client link is empty.
- The quote screen now detects when the copied client name and saved client record disagree.
- A prominent correction panel shows the mismatch and lets staff permanently reassign the quote, source enquiry, survey and downstream jobs to the correct saved client.
- Exact client-name matches are suggested before email matches, avoiding false matches where one staff email is used for several organisations.
- Existing-client quote creation now locks the business name to the selected client record, preventing the displayed name and hidden client ID from separating.
- New quotes opened from an enquiry prefer a unique exact name match over a stale enquiry client link.

App and WordPress catalogue version updated to **V26.09.17.02**.

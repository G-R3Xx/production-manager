# Production Manager V26.08.27.06

## V26.08.27.06

- Artwork Approval sign specifications now include a dedicated Colour row using the quote line substrate/colour selection and relevant customer-facing option values.
- Artwork Approval sign specifications now include Pickup / delivery / install using the dispatch choice saved on the originating quote line.
- Added monochrome approval-spec icons for Colour, Pickup, Delivery and Install.
- Draft artwork approvals rebuild their specification from the current quote line so these new fields appear on existing unsent approvals; the current specification is captured when the approval is sent so released revisions remain frozen.
- Client approval wording now includes colour and pickup / delivery / install details.
